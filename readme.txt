Prize wheel popup for WooCommerce with email capture and coupon code delivery.

== Description ==

Design Cart Spin To Win is a prize wheel popup for WooCommerce. Customers spin the wheel, enter an email address, and receive a discount code by email. Collected emails are stored in the admin panel with CSV export.

Author: Pawel Nosko
Company: Design Cart — https://www.designcart.pl

== Installation ==

1. Upload the `design-cart-spin-to-win` folder to `/wp-content/plugins/`.
2. Activate the plugin through the Plugins menu (WooCommerce required).
3. Open the Spin To Win menu in the WordPress admin.
